# 使用指南

本文面向第一次使用 live-chat-eval 的测试者。

## 打开应用

按 [部署说明](deployment.md) 启动服务后，在浏览器打开 **http://localhost:8787**。

应用分四个顶层页面（左侧导航）：

| 页面 | 说明 |
|------|------|
| **直播间** | 实时模拟主播回复、导入历史记录、播放弹幕剧本 |
| **评估分析** | 查看和发起对话会话的评分 |
| **评分标准** | 编辑评分模板（维度与权重） |
| **设置** | 配置模型服务商、主播档案、回复配置 |

---

## 任务路径一：评估已有聊天记录

适合场景：已有主播的真实聊天导出文件，想对这段对话打分。

**第一步：导入记录**

进入「直播间」→ 右上角「导入」→ 上传 `.md` 格式聊天记录（格式见 `fixtures/transcripts/sample-001-chat.md`）。

系统会自动识别发言人，请确认哪个是「主播」、哪个是「观众」。若已有同名主播档案，会自动关联。

**第二步（可选）：配置评分标准**

进入「评分标准」页面，查看或编辑「默认评分」模板，了解各维度和权重。首次可直接使用默认模板。

**说明：**
- 规则维度（如回复率、延迟）无需模型即可计算，导入后即可得分。
- LLM 维度会调用你在设置里配置的裁判模型，每次评估会向该服务发送对话内容并产生费用。如果没有配置裁判模型，LLM 维度将跳过。

**第三步：发起评估**

进入「评估分析」→「新建评估」→ 选择会话和评分模板，点击「开始」。规则评分即时完成，LLM 评分逐条进行并实时更新。

**第四步：查看结果**

评估完成后可看到综合指数、各维度得分和每条主播发言的裁判意见。

---

## 任务路径二：模拟主播回复（实时 / 剧本）

适合场景：测试 AI 主播的回复效果，不需要已有聊天记录。

**第一步：配置模型服务**

进入「设置」→「模型服务」→「添加服务商」，填入服务地址和 API Key（支持 OpenAI 兼容接口、Anthropic、Gemini、Ollama）。保存后可点击「测试连接」确认可用。

**第二步：配置主播**

进入「设置」→「主播档案」，查看或编辑「小鹿」（内置预设），或新建主播，填写人设 Prompt。

进入「设置」→「回复配置」，确认已选择模型；可以调整回复策略（弹幕批量窗口、主动发言触发等）。

**第三步：模拟对话**

有两种方式：

- **单人实时模式**：进入「直播间」→「新建直播间」，直接在输入框发弹幕，主播会实时回复。
- **剧本模式**：进入「直播间」→「新建直播间」→ 切换「剧本」标签，选择或编辑一个弹幕剧本，支持倍速播放、单步回放、跳过等待。

**第四步（可选）：开启实时评估**

在直播间运行期间，点击「开启实时评估」，每条主播回复会自动打分，分数气泡展示在消息上。

## 内置示例

- **主播**：小鹿（活泼开朗风格）
- **回复配置**：默认配置
- **剧本**：示例剧本（5 条弹幕，演示基本回复流）
- **评分模板**：默认评分
- **样例聊天记录**：`fixtures/transcripts/sample-001-chat.md`（脱敏，可直接导入）

首次使用可用内置样例走完完整流程，无需自己准备数据。
