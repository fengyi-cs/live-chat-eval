## 问题反馈模板

遇到问题时，请按以下格式整理：

```
版本：v0.1.0-rc.1
系统：（如 Windows 11 x64）
启动方式：（原生 Node / Docker Compose）
Node 版本（原生）：
问题描述：（一句话）

复现步骤：
1. 
2. 
3. 

期望行为：
实际行为：

诊断输出（`node scripts/doctor.mjs` 结果，请确认无敏感信息后附上）：
启动日志（如有）：
```

**请勿在反馈中包含：**

- API Key 或任何密钥
- 完整数据库文件（`data/app.db`）
- 真实用户聊天记录原文

如需附日志，请先确认无上述内容。
