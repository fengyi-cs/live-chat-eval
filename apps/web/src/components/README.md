# live-chat-eval frontend components

组件可直接从以下路径导入：

```ts
import { Button } from '@/components/ui/button'
import { cn } from '@/lib/utils'
import { ModelPicker } from '@/components/ModelPicker'
```

shadcn 组件：Button, Input, Textarea, Label, Select, Checkbox, Switch, Tabs, Dialog, Sheet, Popover, Command, DropdownMenu, Tooltip, Badge, ScrollArea, Separator。深色模式使用 Tailwind 默认的 prefers-color-scheme 媒体策略，不用 .dark 类。拖拽库：@dnd-kit/core、sortable、utilities。
